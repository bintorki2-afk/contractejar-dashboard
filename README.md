# contractejar-dashboard — لوحة التحكم 🎛️

لوحة إدارة **«عقد إيجار»** — إدارة العقود، الطلبات، الموظفين، المحتوى، والتقارير.
جزء من مشروع **صقر واحد**.

**التقنية:** Next.js 15 (App Router) · عربي RTL · React Query + Zustand · shadcn/ui
**الاستضافة:** Vercel (ينشر تلقائياً من فرع `master`)

## التشغيل محلياً
```bash
cp .env.example .env.local   # ثم عبّئ القيم
npm install
npm run dev                  # http://localhost:3000
```
